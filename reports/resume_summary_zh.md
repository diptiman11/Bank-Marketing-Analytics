# 简历与面试表述

## 项目名称

银行客户营销分析与认购倾向预测

## 简历项目描述

- 基于 UCI 公开的 45,211 条银行营销记录，使用 Python 完成数据校验、特征工程及客户/渠道转化分析，并设计 PostgreSQL 星型数据模型与 Power BI 可导入分析表。
- 对比逻辑回归与随机森林模型，在排除通话时长等数据泄漏字段后构建客户认购倾向模型；最终模型 ROC-AUC 为 0.797、PR-AUC 为 0.451，并生成高、中、低优先级营销名单。
- 搭建 Streamlit 交互式看板，展示营销转化率、客群差异、渠道表现、模型解释和客户优先级，为触达顺序及营销策略优化提供分析依据。

## 一句话介绍

这是一个从公开数据、SQL 建模、业务分析、机器学习到交互式看板的端到端项目，目标是在营销资源有限的情况下，帮助业务团队识别更值得优先触达的潜在客户。

## 面试时重点说明

1. 项目不是只追求预测准确率，而是围绕营销资源分配提出业务问题。
2. 数据中的认购客户仅占约 11.7%，因此主要使用 PR-AUC、召回率和 F1，而不是只看 Accuracy。
3. 通话时长在通话结束后才产生，不能用于触达前预测，所以主动将其从模型特征中排除。
4. 模型输出被转化为高、中、低优先级名单，便于业务人员实际使用。
5. 数据来自葡萄牙银行公开历史记录，项目仅用于展示分析流程，不代表真实银行内部客户决策。
